PREVIEW SECTION PRIX - VERSION COMPAT WINDOWS

1. Extraire entierement le ZIP dans un dossier normal.
2. Double-cliquer sur START-PREVIEW.bat.
3. Le terminal reste ouvert pendant la preview.

Cette version ne lance PAS `npm -v` : elle utilise directement npm.cmd,
comme les anciennes previews qui fonctionnaient.

Si une ancienne installation locale pose probleme :
- lancer RESET-AND-START.bat.

URL manuelle si le navigateur ne s'ouvre pas :
http://127.0.0.1:5173
