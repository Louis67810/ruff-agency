HERO OPTIMISE — PREVIEW SEPAREE

METHODE LA PLUS SIMPLE (WINDOWS)
1. Decompresse le ZIP.
2. Double-clique sur START-PREVIEW.bat.
3. Au premier lancement, npm install sera execute automatiquement.
4. Le navigateur s'ouvre sur http://127.0.0.1:4173
5. Utilise Desktop / Tablet / Mobile en haut de la page.
6. "Rejouer les animations" recharge uniquement le Hero.

METHODE MANUELLE
Ouvre PowerShell dans ce dossier puis :
  npm install
  npm run dev

Ensuite ouvre :
  http://127.0.0.1:4173
