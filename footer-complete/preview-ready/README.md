# Preview autonome du footer

1. Décompresse entièrement le ZIP.
2. Double-clique sur `START.bat`.
3. Au premier lancement, npm installe React 18.3.1, React DOM 18.3.1 et Vite 6.1.0.
4. Vite ouvre automatiquement le bon port dans le navigateur.
5. Laisse la fenêtre noire ouverte pendant la preview.

Aucun projet Next.js n'est nécessaire.
