# Preview autonome — Stack Section 3

Double-clique sur `START.bat` après avoir décompressé le ZIP.

Cette preview ne dépend d'aucun projet Next.js et ne charge aucun runtime JavaScript Framer.

Le premier lancement exécute `npm install` localement pour React, React DOM et Vite. `@vitejs/plugin-react` n'est volontairement pas utilisé afin d'éviter les conflits de peer dependencies rencontrés sur les previews précédentes.
