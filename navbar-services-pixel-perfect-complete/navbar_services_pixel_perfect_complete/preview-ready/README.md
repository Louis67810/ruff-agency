# Preview autonome — Navbar Services Pixel Perfect V2

1. Décompresse entièrement le ZIP.
2. Double-clique sur `START.bat`.
3. Au premier lancement, npm installe React, React DOM, Framer Motion et Vite.
4. Sur desktop, passe la souris sur **Services** pour vérifier le mega-menu corrigé.

Le navigateur est ouvert par Vite sur le port réellement disponible, donc le pack n'impose pas `4173`.
