# Preview — Section Comparatif

## Windows

1. Décompresse le ZIP.
2. Double-clique sur `START-PREVIEW.bat`.
3. Au premier lancement, `npm install` installe uniquement les dépendances de ce dossier.
4. La preview s'ouvre sur `http://127.0.0.1:4173`.
5. Utilise Desktop / Tablet / Mobile pour tester les vrais breakpoints et `Rejouer les animations` pour relancer les effets d'entrée.

Cette preview est indépendante de ton projet principal.
